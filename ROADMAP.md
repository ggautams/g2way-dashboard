# g2way-dashboard roadmap

Feature target: a complete API gateway control plane, with nothing held back
behind a licence — this is a free product. Worked through
top to bottom; the first unchecked box is the next task (see `CLAUDE.md` for the
session protocol). Architecture decisions: `docs/adr/`. Upstream gateway changes:
`UPSTREAM.md`.

The gateway is `../g2way`. Look things up through `contracts/` and
`docs/g2way-map.md` before ever reading its source — see `CLAUDE.md`.

## M0 — Scaffolding & workflow

- [x] Next.js 16 App Router + TypeScript strict + Tailwind 4 + ESLint
- [x] `Makefile` with `check` gate (fmt + lint + typecheck + test + build + drift)
- [x] `CLAUDE.md` session-resume protocol, conventions, and the g2way lookup order
- [x] `ROADMAP.md` (this file) seeded with all milestones
- [x] ADR-0001: stack choices (Next.js BFF, SQLite/Drizzle, analytics sources)
- [x] ADR-0002: the g2way contract & drift protocol
- [x] Cross-repo contract layer: `contracts/{watch,openapi,g2way.d.ts,lock}` +
      vendored `g2way-docs/`, generated by `npm run sync:g2way`
- [x] `docs/g2way-map.md` — curated upstream index + the invariants OpenAPI omits
- [x] `UPSTREAM.md` drift journal, seeded with the known upstream blockers
- [x] `check:g2way` drift detector + `.githooks/pre-commit` (`make hooks`)
- [x] git repo with initial commits

**Requires from g2way**: `make openapi` writing `docs/api/openapi.json` — landed
upstream as `feat(admin): dumpable OpenAPI spec` so this repo needs no Rust
toolchain to regenerate its types.

## M1 — Connectivity & shell

- [ ] Environment registry: named gateway targets (URL + admin secret), secrets
      read server-side only, `.env.example` documenting every variable
- [ ] BFF proxy `src/app/api/g2/[...path]/route.ts` — attaches
      `X-G2-Authorization`, forwards method/body/query, passes the gateway's
      error envelope through untouched
- [ ] Typed gateway client over `contracts/g2way.d.ts` (no hand-written types)
- [ ] App shell: nav, dark mode, command palette, toasts
- [ ] Gateway page from `/g2/node` + `/g2/version` + `/g2/health`: live route
      table, per-target health, circuit-breaker state, service-discovery and
      GraphQL schema-sync status
- [ ] Degraded-mode banner when the gateway is unreachable (the dashboard must
      still render, and say why it can't reach it)
- [ ] Test: the admin secret appears nowhere in the client bundle

## M2 — Identity, RBAC & audit

## M5 — Traffic & middleware designer

## Progress log

- M0 complete. Scaffolded the repo next to g2way: Next.js 16.3.4
  (App Router, TS strict, Tailwind 4), `make check` gate mirroring g2way's,
  CLAUDE.md session protocol, ADR-0001/0002, and the whole cross-repo layer.
  First `sync:g2way` produced 2738 lines of `contracts/g2way.d.ts` from the
  gateway's OpenAPI document — and because utoipa carries the Rust rustdoc into
  the schema descriptions, the generated types arrive fully documented, which is
  most of the token-efficiency win on its own. Vendored g2way's 13 docs + 12 ADRs
  into `contracts/g2way-docs/`. Drift detection uses `git rev-parse HEAD:<path>`
  tree/blob OIDs per watched area, so unrelated upstream commits cause no churn
  here; verified end to end (clean → drifted → synced → clean). **Landed one
  enabler commit upstream** (`feat(admin): dumpable OpenAPI spec`): the document
  was only renderable inside `g2-admin`, so this repo would otherwise have needed
  a Rust build and a running gateway just to codegen. It now ships as a committed
  file, and g2way's own `make check` diffs it so it cannot go stale. **Surprises:**
  `create-next-app` pins `@types/node@^20` while this machine runs Node 22 and
  vitest 5 requires `^22` — bumped to match the real runtime. Rustdoc's
  `-D warnings` rejects a public doc comment linking to a private item, which is
  what a first pass at `openapi_json()` did. And three real upstream blockers are
  already recorded in `UPSTREAM.md`: the admin port is on no Service, the k8s
  analytics sink is `otlp_logs` not `redis_list`, and there is still no
  cache-flush endpoint. Next: M1 — the BFF proxy and the environment registry.
